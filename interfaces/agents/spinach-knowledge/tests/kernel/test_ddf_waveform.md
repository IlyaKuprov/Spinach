# Concurrent waveform controls

For a pattern varying only along Z, choosing axial demagnetising factor one gives the same multiplier for all Fourier modes including the mean. The secular feedback torque therefore reduces to a local Z rotation with frequency proportional to instantaneous longitudinal magnetisation. Independent Bloch integration at a selected voxel checks the complex signal through overlapping finite RF and gradient lobes followed by free evolution.

A separate uniform spherical sample has zero distant dipolar field. Enabling resonant coil feedback on this sample gives the Bloembergen–Pound transverse envelope.
