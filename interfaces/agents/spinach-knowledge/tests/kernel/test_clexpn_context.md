Syntax: `result=test_clexpn_context()`

The bath-pumped Hahn contract is checked at five pump placements (including both endpoints and a pulse coincident with refocusing), against the analytic Ising pair. ## Native interface

Explicit probability rows retain the same state order and weights. The native complete-bath record is checked to cover one assignment per physical configuration, using the product of bath multiplicities; native records retain the conditional response in `value` and the separately reduced quotient in `factor`.
