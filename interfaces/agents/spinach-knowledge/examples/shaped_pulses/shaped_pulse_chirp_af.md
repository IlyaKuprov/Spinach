# examples/shaped_pulses/shaped_pulse_chirp_af.m

- Source: [examples/shaped_pulses/shaped_pulse_chirp_af.m](https://github.com/IlyaKuprov/Spinach/blob/main/examples/shaped_pulses/shaped_pulse_chirp_af.m)
- Signature: `shaped_pulse_chirp_af()`

## Purpose

Demonstrate a chirp pulse applied in amplitude-frequency coordinates with Spinach's Fokker–Planck formalism. The source contrasts its point requirements with the two-points-per-period Nyquist–Shannon condition for a `{Cx,Cy}`-parameterised chirp, and estimates a runtime of seconds. Although the source header calls this an inversion pulse, the code itself prepares and detects a simulated signal; it does not report a measured inversion result.

## Spin model and pulse sequence

The model has 31 `1H` spins, scalar Zeeman values linearly spaced from `-4` to `4`, and scalar couplings of `20` between adjacent spins. The source sets `sys.magnet=14.1` but does not state the field unit; it also gives no units for the scalar values or couplings. The basis is `sphten-liouv` with the `IK-2` approximation, scalar-coupling connectivity, and proximity level 1.

The initial state is longitudinal magnetisation from `state(spin_system,'Lz','1H')`; the acquisition coil is `L+`. The acquisition parameters are offset 0, sweep 5100, 2048 points, zero-fill to 8192, and axis units Hz. The WURST waveform is generated by `chirp_pulse(100,0.1,2000,16,'wurst')`, then its frequency coordinates are shifted by 1000. The amplitude-frequency shaped-pulse call uses that waveform with `pi/2` and final argument 2. Next the code applies a homospoil with mode `'destroy'`, then a hard `Ly` pulse of `pi/2`, and acquires using the Hamiltonian, relaxation, and kinetics operators.

## Signal processing and output

The simulated FID is exponentially apodised with parameter 6, Fourier transformed with an 8192-point zero-filled FFT, shifted, and plotted using the real part of the spectrum. The output is a calculated spectrum from the stated spin model and pulse/acquisition sequence, not experimental data. Units for the chirp-generator arguments and the numerical Zeeman/coupling values are not specified in the source beyond the explicitly labelled acquisition axis in Hz.
