# tests/kernel/test_pauli_spin_half_algebra.m

- Signature: `result=test_pauli_spin_half_algebra()`

## Purpose

Tests spin-half angular momentum matrices generated by Spinach.

## Physical / mathematical content

The test checks the spin-half angular momentum algebra, the ladder-operator convention, and the `S^2=s(s+1)` identity for `s=1/2`.

## Numerical / algorithmic content

Generates the spin-half operators with `pauli(2)` and compares them with textbook `Sx`, `Sy`, `Sz`, `S+` and `S−` matrices. It checks `[Sx,Sy]=iSz`, `[Sz,S+]=S+`, `[Sz,S−]=−S−`, and `S^2=3/4` times the identity, using absolute and relative tolerances of `1e-15`.

## Outputs

- `result` — regression test result with explanatory messages.

## Implementation structure

- Announce the test target and state the physical target.
- Generate Spinach spin-half operators and write the textbook matrices explicitly.
- Check the operator matrices against the textbook representation.
- Check the angular momentum commutation relations.
- Check the Casimir operator.
