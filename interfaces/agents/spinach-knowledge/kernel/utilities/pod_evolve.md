# Range-aware evaluation of a fixed POD family

`pod_evolve(model,coefficients,timestep,nsteps)` returns the initial complex observable and a uniform trajectory of the prepared affine model. Inputs and integer counts are double; nsteps is nonnegative and below flintmax. Terms use L=H+1i*R+1i*K in rad/s, time is in seconds, and the sign is exp(-1i*L*t).

Time, coefficients and active terms are decomposed into bounded components and binary exponents. Assembly uses one common exponent frame and restores only the structurally retained summed generator, without trial multiplication orders or fallback chains. Columns use compensated additions based on TwoSum, Ogita et al. DOI:10.1137/030601818 Algorithms3.1/4.1, applied componentwise to the computed scaled terms. If accumulating correction terms loses information and a final entry is zero, the request is rejected before that entry can certify structural disconnection. This is not exact coefficient multiplication or arbitrary-precision summation. Lost nonzero components and an unrepresentable final generator are explicit errors. Zero coefficients are excluded. Sparse terms remain sparse through the exponential-action callback. Directed reachability is repeated on the normalised affine sum before physical restoration, excluding paths removed by exact cancellation.

Initial coordinates and the detector are normalised separately. An estimated real Rayleigh quotient supplies a scalar amplitude shift; it is not an invariance test. Non-diagonal exponential actions update binary-normalised working coordinates. Physical amplitude is carried separately; only the detected Hermitian overlap is restored. A finite observable can therefore remain supported beyond the physical state's double range. A shift whose exponent is outside exact integer range is not used. Unsupported working-array dynamic range, actions that entirely underflow to zero, non-diagonal action norms above flintmax, inexactly representable accumulated exponents and nonfinite final observables are explicit errors. Physical signal underflow follows double arithmetic and can round to zero. A separate analytical bound certifies entirely underflowed future scalar signals from the largest finite complex initial signal; it does not test a computed working action. This is not arbitrary-precision or componentwise-error certification for ill-conditioned dynamics.

Zero-step, zero-duration, all-zero coefficients, zero initial state/detector and exact common-side structural stationary support return constant traces after input validation. A state-side shortcut must hold for every active term, or a detector-side shortcut must hold for every active term; different sides do not combine. The assembled support is also checked. Computed actions are never used to infer zeros because they can underflow. Cancellation-based nullspaces otherwise use the general exponential action; zero initial overlap does not imply a constant signal.

MATLAB expmv implements the Al-Mohy–Higham exponential-action method, DOI:10.1137/100788860. The documented operator callback keeps the explicit scalar shift as the only shift. Actions are streamed in blocks no wider than the reduced rank; a Hermitian-part Gershgorin growth bound limits their range. The full propagator and full trajectory are never formed. Exactly diagonal models use componentwise closed-form exponentials. For non-diagonal generators, the equivalent forward or adjoint action with the lower initial coordinate norm-growth rate is selected; the adjoint result is conjugated to retain the original observable. Native norm estimates preserve caller RNG on acceptance and error. No invariant subspace is inferred from a small computed action. This evaluator does not train, retune rank, change a physical spin_system, infer a metric, subtract references or process spectra. No positivity, trace, stability or observable-error guarantee follows from snapshot energy or orthogonality.

Hermitian detection accumulates real component products by their binary exponents before restoring signal units. Structural directed reachability retains exactly the coordinates on paths from the state to the detector, excluding unrelated unstable blocks. Normalised matrix products explicitly reject unsupported component underflow.

The matrix-product range contract conservatively requires every nonzero operand-component pair to remain nonzero at the working scale; it can reject a physically finite result rather than silently lose a contribution.

Structural reachability traverses term supports implicitly, without constructing an aggregate graph. Dense neighbours use bounded row/column slices; sparse reverse traversal uses stored transposed terms. Each coordinate is queued at most once, with early return once all coordinates are reached. Fixed off-diagonal component ranges are measured once before action blocks; shifted diagonal ranges are checked once per block, outside the callback. Dense range scans use bounded column storage; sparse range scans traverse stored components. Callback checks scan only changing action operands.

The generator diagonal is separated once. Native callbacks combine the off-diagonal product and shifted diagonal action, so scalar shifts do not allocate a second dense generator. Fixed Hermitian row radii, forward/adjoint column norms, and off-diagonal component bounds use sparse absolute row/column sums for sparse generators and bounded row/column scans for dense ones. The half-sum of absolute row and column sums safely bounds sparse Hermitian radii without constructing the Hermitian part. Real states and real actions retain real working storage; genuinely complex contributions are preserved. Rayleigh shifts stream normalised columns; sparse columns contribute scalar overlaps without accumulating a dense vector on every column. No complete normalised generator copy is made. Binary scaling checks stored component counts for underflow without constructing masks of implicit zeros.

Per-term affine workspaces are released before the assembled generator is restored to its physical scale.

Exactly diagonal summed generators use componentwise scalar exponentials, one state column per acquisition step; no dense zero off-diagonal matrix is retained. These actions do not use the generic exponential-action norm cutoff. Non-diagonal actions retain their existing range contract.

Each exactly diagonal mode carries its own binary state amplitude. Only bounded exponential residuals and phases are formed before per-mode renormalisation; Hermitian detection combines component products with their coordinate exponents. This supports finite detected products even when a separate exponential factor or physical state component would overflow or underflow.

Observable alignment may discard underflowed working components only when an exponent bound for the complete computed tail is strictly below half the smallest physical subnormal. The bound uses the largest absolute discarded group and its count, not separate per-mode underflow tests; physically representable collective tails remain explicit range errors.

Diagonal update factors have a cached nonzero component bound. Before each pointwise update, the factor/state component bound must remain in the normal double range; unsupported subnormal products are rejected before zeroing or quantising a small phase. This conservative computed-range restriction may reject a finite physical observable. Normal-boundary phase controls remain supported.
