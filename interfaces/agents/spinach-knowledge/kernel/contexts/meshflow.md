# kernel/contexts/meshflow.m

[MATLAB source](https://github.com/IlyaKuprov/Spinach/blob/main/kernel/contexts/meshflow.m) · [Spinach Wiki](https://spindynamics.org/wiki/index.php?title=meshflow.m)

## Contract

`meshflow(spin_system,pulse_sequence,parameters)` is identified in the source as a first-draft magnetohydrodynamics context for microfluidic simulations. It requires mesh indexing and Voronoi data in `spin_system.mesh`; the mesh is supplied by the mesh/COMSOL import workflow. The spatial dimension is `spin_system.mesh.vor.ncells`, and the spin dimension is `size(spin_system.bas.basis,1)`, in the selected Spinach basis. Thus the combined spatial-spin state/operator dimension is `spc_dim*spn_dim`.

The operator phantoms pair voxel-grid maps with spin-space operators. Each `*_ph` map must have the sample-grid dimensions; the implementation vectorises it with `(:)` to make a diagonal spatial factor. `H_ph`/`H_op`, `R_ph`/`R_op`, and `K_ph`/`K_op` describe Hamiltonian, relaxation-superoperator, and kinetics-superoperator contributions. Initial and detection states use `rho0_ph`/`rho0_st` and `coil_ph`/`coil_st`; the maps encode spatial distribution or sensitivity, and the paired spin states come from `state`. The context forms these as spatial-spin Kronecker/polyadic objects and passes `spc_dim` and `spn_dim` to the sequence.

Spatial motion is generated by `flow_gen(spin_system,parameters)` and acts independently of the spin subspace. Its documented `parameters.diff` is a diffusion coefficient in m²/s and defaults to zero. The current source supplies `G` as a zero placeholder. The pulse-sequence call is `pulse_sequence(spin_system,parameters,H,R,K,G,F)`; the return value is whatever that sequence returns. This context has a voxel axis, not a powder-orientation grid.

## Source-supported example

`examples/microfluidics/plain_flow.m` imports a COMSOL mesh with 2,659 Voronoi cells and sets `parameters.diff=1e-7` m²/s. It supplies a spatially uniform Hamiltonian and relaxation phantom and a voxel-dependent drainage kinetics phantom before calling `meshflow`.
