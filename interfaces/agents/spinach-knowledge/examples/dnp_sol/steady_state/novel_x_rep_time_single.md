# examples/dnp_sol/steady_state/novel_x_rep_time_single.m

## Purpose and call

Call `novel_x_rep_time_single()` with no arguments from MATLAB with Spinach and the example helpers on the path. This is the single-distance counterpart to the distance-ensemble scan: it compares steady-state NOVEL DNP proton signal with and without electron flipback for one electron–proton pair. It has no declared return value and saves a figure. The source estimates minutes of calculation.

Source: [MATLAB example](https://github.com/IlyaKuprov/Spinach/blob/main/examples/dnp_sol/steady_state/novel_x_rep_time_single.m).

## Spin model and configuration

The system contains `E` and `1H`, with `sys.magnet=0.34` for the X-band setup. Trityl electron Zeeman values are `[2.00319 2.00319 2.00258]`; proton values are `[0 0 5]` (source description: ppm guess), with orientations `(pi/180)*{[0 10 0],[0 0 10]}`. The spin-temperature parameter is `80`; no unit is stated. The electron coordinate is the origin and the proton coordinate is `(0,0,3.500)`, with the source labelling the distance in Å.

The calculation uses the `sphten-liouv` basis without approximation, `prop_chop=1e-12`, and disables hygiene. Relaxation is `t1_t2`, diagonal retention, and DiBari equilibrium; the nuclear R1 function is `r1n_dnp(...,2.00230,1e-3,26,r_en,bet)`. The remaining relaxation entries are `1e3` and `[200e3 50e3]`, with no units specified for those values in this file. See [r1n_dnp.m](https://github.com/IlyaKuprov/Spinach/blob/main/etc/textbook/r1n_dnp.m).

## Repetition-time scan

Electron nutation frequency is `15e6` Hz; contact duration is `500e-9` seconds and pulse duration is `1/(4*irr_powers)` (commented as seconds). The experiment also sets `flippulse=1`, `addshift=-3.3e6`, `el_offs=0e6`, and powder grid `rep_2ang_800pts_sph`. Detection uses `coil_state(spin_system,'Lz','1H','exact')` and the experiment spins are `{'E','1H'}`. Thirty values are generated by `logspace(-4,-2,30)`; the plot converts the horizontal values by `1e3` and labels them in ms.

For each repetition time the code evaluates `powder` with `@noveldnp_steady` and `esr` twice. It sets `flipback=0` and computes shot spacing after one pulse plus contact, then sets `flipback=1` and computes spacing after two pulses plus contact. Unlike the ensemble variants, this function does not loop over distances or B1 values and applies no quadrature average. The helper is [noveldnp_steady.m](https://github.com/IlyaKuprov/Spinach/blob/main/experiments/hyperpol/noveldnp_steady.m).

## Dependencies

The source uses Spinach system construction and propagation functions `create`, `basis`, `state`, and `powder`, the `gaussleg` quadrature helper, and MATLAB `parfor`; plotting uses `kfigure`, `kylabel`, and `klegend` before MATLAB `savefig`. The NOVEL propagator and R1 helper are linked above.

## Output and scope

The saved figure `novel_x_rep_time_single.fig` plots the real proton longitudinal expectation value for both flipback conditions. It is the selected 3.5 Å pair under this parameterisation, not the distance-averaged result from companion ensemble examples. The source uses `parfor` over repetition times and does not configure a worker count.
