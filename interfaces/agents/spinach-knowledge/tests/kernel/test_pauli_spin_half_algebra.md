# tests/kernel/test_pauli_spin_half_algebra.m

## Purpose

Regression test that verifies the spin-half angular momentum operators generated by Spinach satisfy the su(2) commutation algebra, the ladder-operator convention, and the S^2 = s(s+1) identity for s = 1/2.

## Behaviour

- Announces the test target with `fprintf('TESTING: Spin-half angular momentum algebra\n')`.
- Initialises a test result object via `new_test_result('kernel/pauli_spin_half_algebra', 'Spin-half angular momentum algebra', 'Spin-half operators must realise the su(2) algebra and S^2=3/4.')`.
- Generates spin-half operators with `S=pauli(2)`.
- Compares the generated operators against explicit textbook matrices:
  - `Sx=[0 1;1 0]/2`
  - `Sy=[0 -1i;1i 0]/2`
  - `Sz=[1 0;0 -1]/2`
  - `Sp=[0 1;0 0]` (raising operator)
  - `Sm=[0 0;1 0]` (lowering operator)
- Checks the angular momentum commutation relations:
  - `[Sx,Sy] = i*Sz`
  - `[Sz,S+] = S+`
  - `[Sz,S-] = -S-`
- Checks the Casimir operator `S2 = Sx*Sx + Sy*Sy + Sz*Sz` equals `0.75*S.u` (the s = 1/2 eigenvalue 3/4 times the identity).
- All comparisons use `test_close` with absolute and relative tolerances of `1e-15`.

## Inputs and outputs

- **Inputs:** none.
- **Outputs:** `result` — regression test result structure with explanatory messages, returned by the function.
