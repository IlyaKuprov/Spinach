# examples/nmr_paramag/gau_density.m

- Signature: `gau_density()`

## Purpose

Simple calculation of the PCS field of a Gaussian distribution of the electron probability density.

## Physical / mathematical content

A three-dimensional Gaussian electron-probability density is used as the source for the distributed PCS field. The calculation compares the field generated by the Kuprov equation with this prescribed density and rotated susceptibility tensor.

## Numerical / algorithmic content

The example uses a 100-point grid in each dimension over coordinates from −10 to 10, with `sigma=0.5`. It rotates the diagonal susceptibility tensor `diag([-0.1, -0.2, 0.3])` using Euler angles `[pi/4, pi/5, pi/6]`, evaluates the Gaussian density, and calls `kpcs` with the FFT method before plotting the PCS field.

## Implementation structure

- Set the grid and density parameters.
- Construct the three-dimensional grid and Gaussian electron density.
- Rotate the susceptibility tensor, solve for the PCS field with `kpcs`, and plot it.
