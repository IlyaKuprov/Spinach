# bath_pumped_hahn

Syntax: `[E,aux]=bath_pumped_hahn(spin_system,parameters,H,R,K)`

Experiment owns validation, preparation and detection through cce_observation. times gives total elapsed sequence duration in seconds. Normalized signal defaults to true and uses the actual detected preparation reference. Explicit rho0/coil or preparation descriptors override the transition preparation. Hahn refocusing plus an ideal bath x pi pulse at pump.fraction. pump requires center, halfwidth, units (Hz or rad/s), fraction and allow_empty. Optional sites/species restrict the physical bath. Spectral boundaries are inclusive. With `parameters.cce.meanfield='none'`, selected exterior spins are omitted from each retained marginal bath state, including the empty cluster. With static conditioning, a selected exterior spin is rejected: a fixed mean field cannot represent its rotation.

Bath-pumped Hahn evaluation uses `clexpn(spin_system,@bath_pumped_hahn,parameters,assumptions)`. The five-argument experiment optionally returns `[E,aux]`; coherent projected propagation supplies spectral residuals, Hamiltonian round-off bounds and signal error estimates to the native reducer. The pump selects canonical axial Zeeman frequencies, with explicit Hz or rad/s units, an inclusive nonnegative halfwidth, a fraction in [0,1], logical allow_empty, and optional distinct physical bath sites or isotope-label cells. No-field product-density ensembles allow selected spins outside a retained cluster; static exterior mean-field pumping remains explicitly unsupported.
