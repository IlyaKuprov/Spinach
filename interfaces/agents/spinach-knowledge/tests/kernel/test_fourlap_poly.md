# tests/kernel/test_fourlap_poly.m

[MATLAB source](https://github.com/IlyaKuprov/Spinach/blob/main/tests/kernel/test_fourlap_poly.m)

`test_fourlap_poly()` checks: Actions and adjoints of periodic spectral Laplacians, unequal periods, odd/even grids in one to three dimensions, constant modes, diffusion propagation, and the even-grid second-derivative Nyquist eigenvalue. It returns the standard Spinach regression-result structure.
