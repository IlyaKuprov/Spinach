# kernel/step.m

- Signature: `rho=step(spin_system,L,rho,time_step)`

## Purpose

Applies a propagation step without explicitly forming the matrix exponential. Supports one-, two-, and three-point product quadratures. Syntax: `rho=step(spin_system,L,rho,time_step)`.

## Physical / mathematical content

For density matrices, the step applies the evolution generated by `L` on both sides; for state vectors, it applies the exponential to the vector. Two- and three-point generator samples are combined using piecewise-linear and piecewise-quadratic rules, respectively.

## Numerical / algorithmic content

The implementation uses a reordered Taylor-times-vector procedure for state vectors and a commutator series for density matrices, with time-step subdivision based on a generator norm. It uses MATLAB `expm` for sufficiently small density matrices. GPU transfer and parallel loops are supported when enabled and applicable. The source notes that an earlier Krylov-subspace implementation was inferior in testing to the current reordered Taylor process.

## Parameters / inputs

- `L` - Liouvillian or Hamiltonian for propagation. One matrix gives the centre-point piecewise-constant rule; two matrices `{left, right}` give the piecewise-linear rule; three matrices `{left, midpoint, right}` give the piecewise-quadratic rule. If `L` is assembled manually from Hamiltonian commutation superoperator `H`, relaxation superoperator `R`, and kinetics superoperator `K`, use `L=H+1i*R+1i*K`. State-dependent evolution generators are supported: if `L{1}` is a function handle (see `iserstep.m` documentation), `L{2}` is the current time and `L{3}` is the method (see `iserstep.m` documentation), the problem is routed to the appropriate Lie-group solver.
- `rho` - state vector or density matrix.
- `time_step` - length of the time step to take.

## Outputs

- `rho` - state vector or density matrix after propagation.

## Implementation structure

- Routes state-dependent generators to `iserstep`; otherwise checks inputs, optionally moves generators and states to the GPU, and chooses the propagation path by formalism. Large cases are divided into substeps and processed by the Taylor-times-vector or commutator-series routine; density-matrix evolution can be parallelised over a stack of states.
