# Proton source and carbon tracer

A proton longitudinal grating is superposed on uniform carbon polarisation. Both species start tilted, in separated rotating frames. The example compares the phase at one face of the box with carbon contributing either zero or 0.03 A/m per reference projection after calibration; proton contributes 0.05 A/m at unit phantom amplitude. Carbon is detectable in both shots. Changing its source scale changes the field acting back on protons, rather than redefining the receiver.

This is a synthetic two-substance control, not an experimental fit. Each substance has its own reflecting diffusion operator. The magnetostatic field uses a periodic box with an axial-needle uniform mode; this choice is independent of the reflecting transport boundary.
