# kernel/cce/cce_graph.m

## Native role and invocation

Internal physical bath connectivity service. clexpn supplies the resolved parameters.

Public simulations enter through `clexpn(spin_system,pulse_sequence,parameters,assumptions)` with a registered experiment.

Internal/expert signature: `graph=cce_graph(spin_system,parameters)`. Engine records are not public experiment parameter structures.

[MATLAB source](../../../../../kernel/cce/cce_graph.m)

## Purpose

Construct the bath connectivity that defines the clusters.

## Behaviour

- Joins two bath spins when `create` kept a coupling between them, in stable bath-ID order; the connectivity therefore follows `sys.tols.prox_cutoff`, `sys.tols.inter_cutoff` and the supplied couplings.
- Uses the spectral norm of the spin-operator pair interaction, built from stock `pauli` matrices, as the pair norm and the cluster ranking score.
- In generalised expansions without noise, and in second-order projected expansions, also joins bath spins that are each coupled to an observed spin, unless `parameters.cce.mediated=false`.
- Keeps disconnected vertices available to singleton clusters.

## Inputs and outputs

**Inputs**

- `spin_system` — compiled spin system with coordinates in Angstrom and pair records (`ids`, real Cartesian `tensor` in rad/s).
- `parameters` — `observed`, `cce.bath_spins`, `cce.approximation`, `cce.second_order`, logical `cce.mediated`, and optional `cce.bath_radius` (Angstrom).

**Outputs**

- `graph` — bath_ids, sparse logical adjacency, scores (equal to pair_norm), pair_norm, observed_mediated, and omitted_bath_ids.

Second-order projected CCE also retains bath edges mediated by the joint observed-spin system unless `parameters.cce.mediated=false`; these edges carry the cross terms generated by the virtual-level susceptibility, even when the bare bath pair tensor vanishes.

For unconnected noise, the cluster graph joins observable-support sites even without a bare Hamiltonian edge, retaining disconnected moment products. Sampled connected noise retains the same support edges to preserve cross-site covariance of the actual finite sampled mixture; deterministic product-state connected noise keeps the ordinary coupling graph. Both ordered and symmetrised reductions use this common graph.

Native noise descriptors carry physical bath-spin support without building a full-bath matrix. Graph selection uses these supports for unconnected or sampled noise, preserving cross terms. The native context computes optional parameters.spectrum only after ensemble reduction and returns diagnostics.spectrum; the Fourier convention remains explicit.

## Internal physical selection option

This table describes the retained graph engine input, not an additional public context signature.

| Field at the engine parameter root | Meaning |
|---|---|
| `bath_radius` | Maximum distance in Angstrom from an observed spin for retaining a bath site; default Inf. |

Validation is local to this service and its consumed numerical records. Public experiment and approximation options are validated by `cce_options` before native context dispatch.

Bath pair norms and scores are sparse. The bath radius includes the cutoff shell; a shared observed subsystem can still induce a complete mediated subgraph.
