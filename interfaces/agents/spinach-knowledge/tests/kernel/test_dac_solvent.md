# tests/kernel/test_dac_solvent.m

Checks the shared Diels–Alder input retains thirty proton labels, five spin-bearing parts, unit reference populations, 2 ppm solvent shifts, empty solvent coordinates, zero solvent scalar couplings, and the original 0.5 s⁻¹ solvent R1/R2 rates. Reaction records omit the solvent. A one-spin-order truncation exercises combined Redfield/T1–T2 relaxation and explicitly unexcited solvent preparation; it is not a full spectral comparison.
