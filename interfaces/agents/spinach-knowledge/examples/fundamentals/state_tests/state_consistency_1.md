# examples/fundamentals/state_tests/state_consistency_1.m

[Source code](https://github.com/IlyaKuprov/Spinach/blob/main/examples/fundamentals/state_tests/state_consistency_1.m)

## Purpose

This example checks state-construction identities in three Spinach formalisms: zeeman-hilb, zeeman-liouv, and sphten-liouv. It tests whether selected singlet/triplet state sets reconstruct the unit state for two-spin pairs and for four-spin product states.

## System and method

Each formalism uses a system of four 1H spins at magnet field 14.1, with all four Zeeman scalar entries set to zero. The basis uses approximation='none'; the source also hushes output and disables the hygiene step while creating the system.

For every ordered pair among the four spins (12 pairs), the test constructs the pair singlet and the three triplet states. It sums those four states and compares the result with the unit state on that pair. For the four-spin check, it iterates over all 24 permutations of the four spin indices. For each ordering, it sums the 16 listed products of pair singlet/triplet states, generated by four_spin_states, and compares the sum with the four-spin unit state.

## Check and output

Both identities use the L1 norm of the residual and fail when it exceeds 1e-6. A failure raises a formalism-specific state construction test FAILED error. If all checks finish for a formalism, the script prints a formalism-specific state construction test PASSED message.

These are finite-dimensional state-construction checks for a four-proton system with zero Zeeman terms. They do not test spin dynamics, nonzero Zeeman interactions, other spin species, or whether the same identities hold under a truncated basis; all three checks explicitly use approximation='none'.
