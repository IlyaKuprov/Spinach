# etc/gui/IO Formats/Orca.cpp

[Implementation](https://github.com/IlyaKuprov/Spinach/blob/main/etc/gui/IO%20Formats/Orca.cpp)

Import the main ORCA text output, not a cube, GBW file or input deck. The GUI looks for the ORCA version banner and the last Cartesian geometry. The angstrom table takes priority over its accompanying atomic-unit table; the latter also supplies masses. When only the atomic-unit geometry is available, coordinates are converted with 0.529177249 Å/bohr. An echoed inline XYZ geometry is a fallback for outputs with Cartesian printing suppressed: it describes the input, not an unprinted optimized structure. Dummy, ghost and capped sites are not GUI spins; property indices still refer to positions in the original zero-based table.

An explicitly requested magnetic isotope that is absent from the GUI isotope table is an import error, not a request to substitute another isotope. Where only a geometry-table atomic weight is available, an absent mass match uses the GUI default for that element.

The electronic g matrix and zero-field splitting (cm⁻¹) are attached to one electron. HFC matrices are already in MHz; the printed nucleus number selects the nucleus, not the order in which ORCA prints properties. Both older **Raw HFC** and newer **Total HFC** headings occur. With HFC but no g matrix the editor keeps its free-electron g default. Nuclear shielding is **shielding in ppm**, not a shift in MHz: an older dimensionless raw shielding block requires a factor of 10⁶; a modern total in ppm does not. Reference shielding separately when converting to shifts. Total spin-spin matrices yield scalar J in Hz (one third of the trace). Tensor storage in the GUI is symmetric, so for non-symmetric input compare against the symmetric part rather than a single off-diagonal entry.

The electric-field gradient is not itself a quadrupolar coupling. Where the output gives the isotope, spin I and moment Q in barns, the importer removes the isotropic part and uses the spin-dependent denominator 2I(2I−1) to form a quadrupolar Hamiltonian tensor in MHz. ORCA may report different hyperfine and quadrupole isotopes at the same site (for example ¹H and ²H). A GUI atom can represent only one isotope: the hyperfine isotope takes precedence when HFC is present; a quadrupole for an alternative isotope must not be attached to it. Temperature-dependent molar χT is a series, not the GUI's single molecular susceptibility value. It is not silently substituted for that field.
