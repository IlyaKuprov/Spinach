## Purpose

Applies an imported HiPER antenna/instrument filter kernel to a shaped complex pulse, then compares that calculated filtered waveform with a separately imported pulse recorded at the instrument. This is a signal-processing comparison; the script does not itself simulate spin dynamics or establish a hardware-validation result.

## Inputs and calculation

The input waveform is read from shaped_pulse_inp.mat as time_ns, real_part and imag_part, and plotted as real and imaginary amplitudes against time in nanoseconds. The filter coefficients h are loaded from hiper_kernel_antenna.mat; the code combines the input components into the complex envelope x=real_part+1i*imag_part, computes the linear convolution with h, and retains the first numel(x) samples. That truncated convolution is the calculated “ideal + filter function” trace, shown as real and imaginary parts on the input time axis.

The measured comparison trace is imported from shaped_pulse_out.mat, not generated by the convolution. Its real and imaginary arrays and time axis are cropped to MATLAB indices 174:934, then the cropped time is shifted so its first sample is zero. The final panel plots this cropped, re-zeroed record alongside the same nanosecond and arbitrary-amplitude labels.

## Scope and interpretation

The three-panel figure juxtaposes the input pulse, the convolution-based filtered prediction, and the imported output record. The source does not report a residual, fit statistic, or quantitative agreement criterion, and the imported files are not included or interpreted here; visual comparison alone should not be described as a calibration result. The antenna kernel's measured or fitted provenance and its sampling interval must be established from the kernel file or its accompanying documentation, not inferred from this application script.
