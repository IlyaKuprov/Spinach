# examples/kinetics/mas_exchange_1.m

- Signature: `mas_exchange_1()`

## Purpose

Two-site position exchange for a deuterium nucleus. The sites differ in chemical shift and quadrupolar-tensor orientation. Calculation time: seconds.

## Physical / mathematical content

The system has two ²H sites at 0 and 3 ppm, each with a quadrupolar interaction generated by `weblab2nqi`. A symmetric two-site exchange matrix uses 2×10⁴ s⁻¹ in each direction and equal concentrations. The sequence starts from a chemical-subsystem raising state and detects the total ²H raising coherence.

## Numerical / algorithmic content

The signal is calculated by a single-rotor acquisition, exponentially apodised (6 s⁻¹), zero-filled to 1024 points, and Fourier transformed. The rotor rate, rotation axis, and powder grid are supplied as acquisition parameters; the displayed axis is in Hz and inverted.

## Implementation structure

- Sets B₀ = 9.4 T, two ²H sites, and the full (untruncated) spin-space basis.
- Uses a 400 kHz sweep, 1024 acquired points, and 1024-point zero filling.
- Sets MAS rate to 25 kHz, axis [1 1 1], and grid `rep_2ang_200pts_sph` with maximum rank 12.
- Calls `singlerot`, applies exponential apodisation, then plots the real Fourier spectrum.
