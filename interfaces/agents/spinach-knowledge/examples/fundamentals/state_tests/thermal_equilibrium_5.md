# examples/fundamentals/state_tests/thermal_equilibrium_5.m

- Signature: `thermal_equilibrium_5()`

## Purpose

Cross-formalism test of state recovery towards the thermodynamic equilibrium.

## Physical / mathematical content

Uses a four-19F system at 9.4 T with damp relaxation, full (`labframe`) retention, temperature 40 K, and damping rate 5.0. It compares `sphten-liouv` and `zeeman-liouv`, using both `dibari` and `IME` thermalisation.

## Numerical / algorithmic content

For each formalism-method pair, the code obtains equilibrium, flips the 19F magnetisation by a pi rotation generated by `Lx`, then propagates the `Lz` observable with the Hamiltonian-plus-relaxation generator. It compares the four recovery trajectories pairwise; the largest normalized difference must not exceed `1e-3`.
