# examples/imaging/spiral_2d.m

- Signature: `spiral_2d()`

## Purpose

Runs a 2D spiral k-space acquisition and displays the recorded image alongside the R1 and R2 phantom maps. The source estimates minutes of runtime.

## Model and acquisition

The model is one `1H` at 5.9 T with zero chemical shift, diagonal T1/T2 relaxation, zero equilibrium, and rates `r1 = 30`, `r2 = 70`. The 0.30 m by 0.25 m sample is represented on a `[108 90]` grid. The source loads R1 and R2 maps from `../../etc/phantoms/letter_a.mat`; the initial-density and receive-coil phantoms are uniform.

The spiral uses gradient amplitude `5e-2`, duration `5e-3 s`, 3000 points, frequency `5e4`, and echo time `0.050 s`. Diffusion is zero and both flow components are set to zero.

## Computation and output

The signal is generated by `imaging(spin_system,@spiral,parameters)`. The script converts the spiral-gradient settings for display, then plots the recorded image and the R1 and R2 phantoms.
