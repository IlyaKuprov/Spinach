# examples/nmr_liquids/hetcor_sucrose.m

- MATLAB implementation: [examples/nmr_liquids/hetcor_sucrose.m](https://github.com/IlyaKuprov/Spinach/blob/main/examples/nmr_liquids/hetcor_sucrose.m)

- Signature: `hetcor_sucrose()`

## Purpose and spin system

Magnitude-mode liquid-state HETCOR for sucrose at natural 13C abundance; the source comment estimates minutes of calculation time. The wrapper parses `../standard_systems/sucrose.log` as a vacuum-DFT spin system and maps H/C atoms to `1H`/`13C`. It sets `options.min_j=3.0` and `options.no_xyz=1`, then replaces isotropic shifts at spin indices `[1:19 24:30]` with the following source values (units are not specified in the example):

```text
[94.5 73.4 74.9 71.5 74.7 62.4 63.6 106.0 78.7 76.3 83.7 64.7 5.49 3.63 3.83 3.54 3.90 3.90 3.90 3.75 3.75 4.29 4.12 3.96 3.90 3.90]
```

## Acquisition and simulation

The wrapper sets `sys.magnet=5.9`, enables `greedy` with proximity cutoff 4.0, and uses `sphten-liouv` / `IK-2`, scalar-coupling connectivity, and proximity level 1. It requests `J=140` Hz, sweeps `[1000 3350]` Hz, offsets `[1200 5000]` (units not stated here), `[256 256]` points, and `[512 512]` zero-fill points. With `spins={'1H','13C'}`, F1 is proton and F2 is carbon; it decouples `1H` and labels both axes in ppm. Natural-abundance 13C isotopomers are generated by `dilute`.

The wrapper calls `liquid(...,@hetcor,parameters,'nmr')`; the separate `experiments/nmr_liquids/hetcor.m` pulse program starts with proton longitudinal magnetisation, detects on carbon, and uses the HETCOR transfer delays `1/(2J)` and `1/(3J)`. The `liquid` context supplies Hamiltonian, relaxation, and kinetics superoperators; this example sets no relaxation rates or model. The wrapper parallel-simulates isotopomers, applies cosine apodisation in both dimensions, sums shifted 2D Fourier transforms, and plots the absolute spectrum in positive mode. Pulse-program reference: https://doi.org/10.1016/0022-2364(81)90272-9.
