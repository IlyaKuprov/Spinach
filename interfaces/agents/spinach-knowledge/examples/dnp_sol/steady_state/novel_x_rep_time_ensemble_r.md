# examples/dnp_sol/steady_state/novel_x_rep_time_ensemble_r.m

## Purpose and call

Call `novel_x_rep_time_ensemble_r()` with no arguments from MATLAB with Spinach and the example helpers on the path. It compares steady-state NOVEL DNP proton signal with and without electron flipback while averaging over electron–proton distance. It declares no return value; it saves a figure. The source estimates minutes of calculation.

Source: [MATLAB example](https://github.com/IlyaKuprov/Spinach/blob/main/examples/dnp_sol/steady_state/novel_x_rep_time_ensemble_r.m).

## Spin model and configuration

The model is an `E`/`1H` pair at an X-band magnet setting `sys.magnet=0.34`. It uses trityl electron Zeeman values `[2.00319 2.00319 2.00258]`, proton values `[0 0 5]` (described in source as a ppm guess), and orientations `(pi/180)*{[0 10 0],[0 0 10]}`. The spin-temperature parameter is `80`; no unit is stated. The basis is `sphten-liouv` with no approximation and propagator chop tolerance `1e-12`; hygiene is disabled.

Relaxation is `t1_t2` with diagonal retention and DiBari equilibrium. The proton R1 function is `r1n_dnp(sys.magnet,inter.temperature,2.00230,1e-3,26,r,bet)`; the other configured relaxation entries are `1e3` and `[200e3 50e3]`. The source does not annotate units for these rate values. See [r1n_dnp.m](https://github.com/IlyaKuprov/Spinach/blob/main/etc/textbook/r1n_dnp.m).

## Scan and averaging

A four-node Gauss–Legendre quadrature spans 3.5–20 Å; the proton is placed at `(0,0,r)` for each node. Repetition times are generated by `logspace(-4,-2,30)` and displayed after multiplication by `1e3` on an axis labelled ms. Electron nutation frequency is fixed at `15e6` Hz. Other experiment settings are a `500e-9`-second contact duration, `pulse_dur=1/(4*irr_powers)` (commented as seconds), `flippulse=1`, `addshift=-3.3e6`, `el_offs=0e6`, and powder grid `rep_2ang_800pts_sph`. Detection uses `state(spin_system,'Lz','1H')` and the experiment spins are `{'E','1H'}`.

For each distance and repetition time the function evaluates `powder(spin_system,@noveldnp_steady,localpar,'esr')` twice. No-flipback shot spacing subtracts one pulse and the contact interval; flipback spacing subtracts two pulses and the contact interval. Distance averaging uses the Gauss–Legendre weights multiplied by `r^2`, normalised by their sum. The propagation helper is [noveldnp_steady.m](https://github.com/IlyaKuprov/Spinach/blob/main/experiments/hyperpol/noveldnp_steady.m).

## Dependencies

The source uses Spinach system construction and propagation functions `create`, `basis`, `state`, and `powder`, the `gaussleg` quadrature helper, and MATLAB `parfor`; plotting uses `kfigure`, `kylabel`, and `klegend` before MATLAB `savefig`. The NOVEL propagator and R1 helper are linked above.

## Output and scope

The figure `novel_x_rep_time_ensemble_r.fig` plots the real proton longitudinal expectation value versus repetition time for the two flipback conditions. It is the result of the stated four-node distance quadrature, not a single-pair result or an experimental curve. The source uses `parfor` across repetition-time points and does not set a worker count.
