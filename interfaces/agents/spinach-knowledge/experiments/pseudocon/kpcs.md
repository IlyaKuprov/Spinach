# experiments/pseudocon/kpcs.m

[MATLAB source](https://github.com/IlyaKuprov/Spinach/blob/main/experiments/pseudocon/kpcs.m) · [Spin Dynamics Wiki](https://spindynamics.org/wiki/index.php?title=kpcs.m)

## Purpose

Computes the forward pseudocontact-shift (PCS) field generated by an unpaired-electron probability-density cube and samples it at nuclear coordinates. The input is explicitly a probability density, not a spin-density cube. This is a field-calculation utility, not a pulse-sequence simulator. The Kuprov-equation method is described in [10.1039/C4CP03106G](https://doi.org/10.1039/C4CP03106G).

## Inputs and grid

Call as `[pcs_vals,pcs_cube] = kpcs(probden,chi,ranges,nxyz,method)`. `probden` is a real, non-negative three-dimensional cube on a regular Cartesian grid. The routine uses the values as supplied; it does not normalise the density. `chi` is a real 3-by-3 susceptibility tensor in Å³. `ranges` is `[xmin xmax ymin ymax zmin zmax]` in Å and defines the grid extents. `nxyz` is an N-by-3 array of nuclear coordinates in Å. `method` must select `fft` or `fdiff`.

## Calculation

The tensor is reduced to its rank-2 anisotropic component. For `fft`, the code builds Fourier derivative multipliers from the grid spacings, forms the Laplacian symbol `L = X^2+Y^2+Z^2`, and the Kuprov symbol `K = -(1/3) q^T chi q` for the Fourier-coordinate vector `q = [X Y Z]`. It evaluates the PCS cube as `1e6 * real(ifftn((K/L).*fftn(probden)))`, setting the singular zero mode of `L` to one before division.

For `fdiff`, three-point finite-difference Laplacian and Kuprov operators are assembled on the same grid, and the linear system is solved with `cgs` using tolerance `1e-10` and a maximum of `1000` iterations. The source labels the finite-difference stencils as minimal three-point schemes.

## Outputs and constraints

`pcs_cube` is the calculated PCS field on the input grid, in ppm. `pcs_vals` contains that field interpolated at each row of `nxyz` using cubic interpolation. The function checks that the density cube is numeric, real, non-negative, and three-dimensional; `chi` must be real and 3-by-3, and `ranges` must contain six real, increasing axis limits.
