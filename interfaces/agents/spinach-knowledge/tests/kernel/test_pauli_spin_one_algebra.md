# tests/kernel/test_pauli_spin_one_algebra.m

**Source:** [https://github.com/IlyaKuprov/Spinach/blob/main/tests/kernel/test_pauli_spin_one_algebra.m](https://github.com/IlyaKuprov/Spinach/blob/main/tests/kernel/test_pauli_spin_one_algebra.m)

## Purpose

Regression test that verifies the spin-one angular momentum matrices generated by `pauli(3)` realise the su(2) algebra, with the Casimir eigenvalue S^2 = s(s+1) = 2.

## Behaviour

- Announces the test target with `fprintf('TESTING: Spin-one angular momentum algebra\n')`.
- Initialises a test result via `new_test_result('kernel/pauli_spin_one_algebra', 'Spin-one angular momentum algebra', 'Spin-one operators must realise su(2), with S^2=2.')`.
- Generates Spinach spin-one operators with `S=pauli(3)`.
- Constructs the textbook spin-one matrices explicitly:
  - `Sp=[0 sqrt(2) 0;0 0 sqrt(2);0 0 0]` (raising operator), `Sm=Sp'` (lowering operator).
  - `Sz=diag([1 0 -1])`.
  - `Sx=(Sp+Sm)/2` and `Sy=(Sp-Sm)/2i`.
- Compares the generated operators against the textbook matrices using `test_close` with absolute and relative tolerances of `1e-15`:
  - `S.z` against `Sz` — spin-one magnetic quantum numbers are +1, 0, and -1.
  - `S.p` against `Sp` — ladder matrix elements are sqrt(s(s+1)-m(m+1)).
  - `S.x` against `Sx` — Cartesian Sx is the Hermitian half-sum of S+ and S-.
  - `S.y` against `Sy` — Cartesian Sy is the Hermitian half-difference divided by i.
  - `comm(S.x,S.y)` against `1i*S.z` — the spin-one matrices must obey the same su(2) algebra.
- Checks the Casimir operator `S2=S.x*S.x+S.y*S.y+S.z*S.z` against `2*S.u` with the same tolerances — for s=1 the Casimir eigenvalue is 2.

## Inputs and outputs

- **Outputs:**
  - `result` — regression test result with explanatory messages, accumulated through successive `test_close` calls.
- **Inputs:** none (the function takes no arguments).
