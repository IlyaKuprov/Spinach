# tests/kernel/test_liouville_commutator.m

**Source:** [https://github.com/IlyaKuprov/Spinach/blob/main/tests/kernel/test_liouville_commutator.m](https://github.com/IlyaKuprov/Spinach/blob/main/tests/kernel/test_liouville_commutator.m)

## Purpose

Regression test for Liouville-space commutation superoperators. It verifies that the commutation superoperator generated by `operator()` equals the difference between the left and right product superoperators, i.e. that the Liouville commutator implements `A*rho - rho*A`.

## Behaviour

1. Announces the test target with `fprintf('TESTING: Liouville commutation superoperator\n')`.
2. Initialises a regression test result via `new_test_result` with the identifier `kernel/liouville_commutator`, the description `Liouville commutation superoperator`, and the specification `commutation superoperators must be left multiplication minus right multiplication.`
3. Builds a one-proton Zeeman Liouville-space spin system with:
   - `sys.magnet = 0`
   - `sys.isotopes = {'1H'}`
   - `inter.zeeman.scalar = {0}`
   - `bas.formalism = 'zeeman-liouv'`
   - `bas.approximation = 'none'`
   using `test_spin_system(sys,inter,bas)`.
4. Generates three forms of the same labelled operator with `operator(spin_system,'Lz',1,...)`:
   - `L_comm` using the `'comm'` option (commutation superoperator),
   - `L_left` using the `'left'` option (left product superoperator),
   - `L_right` using the `'right'` option (right product superoperator).
5. Checks the superoperator identity with `test_close(result,'comm=left-right',L_comm,L_left-L_right,1e-15,1e-15,...)`, with the message `the Liouville commutator is A*rho-rho*A`. The absolute and relative tolerances are both `1e-15`.

## Inputs and outputs

- **Inputs:** none. The function takes no arguments.
- **Outputs:**
  - `result` — regression test result with explanatory messages.
