# kernel/plotting/write_movie.m

- Signature: `write_movie(file_name)`

## Purpose

Intended to orbit the camera around a 3D plot and write a correctly looping 359-frame movie for presentation-quality graphics generated by `volplot()`, `cst_display()`, `hfc_display()`, and other Spinach plotting utilities.

## Physical / mathematical content

No physical or mathematical model is specified.

## Numerical / algorithmic content

The function calls `axis vis3d` to disable stretch-to-fill, opens an MPEG-4 `VideoWriter` with quality set to 100, and runs a 359-iteration loop. Each iteration pauses for 0.05 seconds and calls `camorbit(1,0)`. The source line containing `writeVideo(writerObj,getframe(gcf))` is a comment, so the loop does not capture or write frames. The writer is closed after the loop.

## Parameters / inputs

- `file_name` — character string naming the output file. The function checks that it is a character array and raises an error otherwise.

## Outputs

- No MATLAB return value. The function opens and closes a video file writer; as written, it does not write frames.

## Implementation structure

- Validate `file_name` with the local `grumble` function.
- Set the axes to `vis3d` mode.
- Create and open the MPEG-4 video writer, with quality 100.
- Pause and orbit the camera through 359 iterations, then close the writer.
