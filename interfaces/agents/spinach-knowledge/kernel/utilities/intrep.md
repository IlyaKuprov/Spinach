# kernel/utilities/intrep.m

- Signature: `Hr=intrep(spin_system,H0,H,T,order)`

## Purpose

Transforms the laboratory-frame Hamiltonian `H=H0+H1` into the interaction representation defined by `H0`, using the requested perturbation-theory order. The method is described in [doi:10.1063/1.4928978](https://doi.org/10.1063/1.4928978).

## Parameters / inputs

- `spin_system` - Spinach spin-system structure.
- `H0` - reference Hamiltonian for the interaction representation, typically the Zeeman Hamiltonian.
- `H` - laboratory-frame Hamiltonian `H0+H1`, typically the full Hamiltonian.
- `T` - period of the propagator generated by `H0`.
- `order` - perturbation-theory order for the rotating-frame transformation; the source permits a nonnegative integer or `Inf`.

## Outputs

- `Hr` - interaction-representation Hamiltonian.

## Numerical / algorithmic content

The function checks that `H0` and `H` are Hermitian, verifies that `T` is a period of the `H0` propagator, and requires the 1-norm of `H1=H-H0` not to exceed that of `H0`. For order zero it returns `H-H0`; for `Inf` it uses the matrix logarithm of the full-Hamiltonian propagator over `T`. At finite positive order it obtains derivatives with `dirdiff` and assembles the perturbation series. The result is symmetrized and passed through `clean_up` using `spin_system.tols.liouv_zero`.

The source notes that the auxiliary-matrix method is much faster than either a commutator series or diagonalisation.
