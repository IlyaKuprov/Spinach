# examples/nmr_proteins/hnco_ubiquitin.m

[Source](https://github.com/IlyaKuprov/Spinach/blob/main/examples/nmr_proteins/hnco_ubiquitin.m)

- Signature: `hnco_ubiquitin()`

## Purpose

A theoretical 3D HNCO simulation for human ubiquitin. The source assumes that only the protein backbone is 13C,15N-labelled and estimates minutes of calculation time, faster with a Tesla A100 GPU. This is a simulated spectrum, not an imported experimental HNCO dataset or a claim of agreement with experiment.

## Protein, spin system, and acquisition

The code calls `protein('1D3Z.pdb','1D3Z.bmrb',options)` with molecule 1, `noshift='delete'`, and `select='backbone-minimal'`. These are structure and shift inputs for constructing the model; the spectrum itself is generated by simulation. The field is 11.7395 T. Interaction and proximity cutoffs are set to 2.0 and 4.0 (the assignments do not state units).

The basis is `sphten-liouv` with the IK-1 approximation, scalar-coupling connectivity, and interaction/proximity levels 4/1. The code enables `greedy` and disables `krylov`. The sequence call is `liquid(...,@hnco,...,'nmr')`; its declared spin channels are `15N`, `13C`, and `1H`. It is a 3D triple-resonance simulation, not an experimental-data load.

The source sets offsets to [-5900, 22050, 4100], sweeps to [2000, 1600, 2900], and acquired point counts to [64, 64, 64], with zero-fill sizes [256, 256, 256]. The delay values are [2.25e-3, 14e-3, 4e-3] s. F1 decoupling is enabled, and displayed axes are in ppm.

## Processing and output

Each of the four phase-cycle components receives squared-cosine apodisation. The code Fourier-transforms the four components in F3, combines conjugate components into positive and negative signals, transforms those in F2 and combines them again, then Fourier-transforms F1. It plots the real part of the resulting 3D spectrum with positive-mode plotting.
