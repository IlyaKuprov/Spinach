# tests/kernel/test_multiprop_adaptive.m

## Purpose

Regression test for adaptive repeated propagator application in `multiprop()`. The test verifies binary adaptive squaring against explicit matrix-power references for state vectors and density matrices, and checks clean-up after propagator squaring.

Source: https://github.com/IlyaKuprov/Spinach/blob/main/tests/kernel/test_multiprop_adaptive.m

## Behaviour

- Announces the test target with `fprintf('TESTING: Adaptive repeated propagator application\n')` and registers a test result via `new_test_result('kernel/multiprop_adaptive', ...)`, stating that `multiprop()` must apply propagators repeatedly by binary adaptive squaring.
- Builds a minimal spin system structure with `sys.enable={}`, `sys.disable={}`, `bas.formalism='zeeman-liouv'`, `tols.prop_chop=0`, `tols.dense_matrix=0.15`, and `tols.small_matrix=200`.
- State-vector propagation: uses the non-normal sparse propagator `P=sparse([0.90 0.10 0.00;0.00 0.80 0.20;0.05 0.00 0.70])`, state `rho=[1.0;2.0;3.0]`, and `N=uint64(13)`; compares `multiprop(spin_system,P,rho,N)` with `(P^double(N))*rho` using `test_close` at tolerances `1e-14` (absolute and relative), noting that Liouville-space and wavefunction states are propagated by left multiplication.
- Sparse diagonal state-vector propagation: uses `P=spdiags([0.95;0.80;0.65],0,3,3)`, `rho=[1.0;2.0;3.0]`, `N=uint64(11)`; compares against `(P^double(N))*rho` at `1e-14`/`1e-14`, noting sparse diagonal propagators follow the generic squaring path.
- Square Liouville-space vector stack: uses the same non-normal sparse propagator, `rho=eye(3)`, `N=uint64(5)`; compares against `(P^double(N))*rho` at `1e-14`/`1e-14`, noting vector stacks are propagated by left multiplication.
- Zero-step shortcut: `multiprop(spin_system,P,rho,0)` must return the state unchanged, checked at `1e-15`/`1e-15`.
- Scalar vector branch: with `bas.formalism='zeeman-wavef'`, `multiprop(spin_system,0.5,2.0,3)` must equal `0.25`, checked at `1e-15`/`1e-15`, noting one-dimensional state vectors follow the vector propagation branch.
- Density-matrix propagation: with `bas.formalism='zeeman-hilb'`, builds `S=pauli(2)`, `H=2*pi*(0.30*S.x+0.70*S.z)`, `P=expm(-1i*H*0.125)`, `rho=S.x+0.25*S.y+0.10*S.z`, `N=15`; compares `multiprop(spin_system,P,rho,N)` with `P_ref*rho*P_ref'` where `P_ref=P^N`, at `1e-13`/`1e-13`, noting Hilbert-space density matrices are propagated by left and right multiplication.
- Sparse density-matrix propagation: uses the non-normal sparse propagator, `rho=sparse([1.0 0.2 0.0;0.2 0.6 0.1;0.0 0.1 0.4])`, `N=uint64(6)`; compares against `P_ref*rho*P_ref'` with `P_ref=P^double(N)` at `1e-14`/`1e-14`, noting sparse Hilbert-space density matrices follow direct binary-power action.
- Sparse diagonal density-matrix propagation: uses `P=spdiags(exp(1i*[0.10;0.20;0.30]),0,3,3)` and a dense Hermitian density matrix, `N=uint64(7)`; compares against `P_ref*rho*P_ref'` with `P_ref=P^double(N)` at `1e-13`/`1e-13`, noting sparse diagonal propagators follow the generic density-matrix path.
- Squaring clean-up: sets `bas.formalism='zeeman-liouv'` and `tols.prop_chop=1e-6`; with `P=speye(2)+sparse([0 1e-8;0 0])` and `rho=[0;1]`, `multiprop(spin_system,P,rho,4)` must return `[0;1]` at `1e-15`/`1e-15`, verifying that small elements generated by propagator squaring are removed.
- Row-vector rejection: calls `multiprop(spin_system,P,[1 0],3)` inside a `try/catch` and uses `test_true` to confirm the call errors, since row vectors are not valid Spinach state vectors.

## Inputs and outputs

```matlab
result = test_multiprop_adaptive()
```

- **Output**: `result` — regression test result structure with explanatory messages, accumulated through `test_close` and `test_true` comparisons.
- The function takes no inputs.
