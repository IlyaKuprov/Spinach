# kernel/grids/voronoisphere.m

- Signature: `[vertices,indices,polygons,sangles]=voronoisphere(xyz)`

## Purpose

Builds a spherical Voronoi tessellation as the geometric dual of the convex-hull triangulation of the supplied directions.

## Input and outputs

- `xyz` is a real finite `3-by-n` array of nonzero vectors. The function normalises every column before constructing the hull, so input radii do not affect the tessellation.
- `vertices` is a `3-by-m` array of spherical Voronoi vertices.
- `indices` is an `n-by-1` cell array. `indices{j}` lists columns of `vertices` incident on the cell generated by normalised `xyz(:,j)`, counterclockwise as viewed from outside.
- `polygons` is an `n-by-1` cell array with `polygons{j}=vertices(:,indices{j})`, in that same order.
- `sangles`, computed only when the fourth output is requested, is an `n-by-1` vector of cell solid angles from `vcell_solidangle(vertices,indices,xyz)`.

## Construction and guards

The function requires at least four points, rejects zero vectors and directions that coincide after normalisation within `uniquetol` tolerance `1e-9`, and rejects sets whose normalised coordinates have `min(svd(xyz)) < 1e-12 * size(xyz,2)`. It computes `convhull(xyz.')`, then requires every undirected hull-triangle edge to occur exactly twice; otherwise it errors rather than returning cells from a non-closed triangulation.

Each hull facet supplies a candidate Voronoi vertex from the normalised cross product of two facet edges. A sign test against the point set selects the side guaranteed empty by the convex-hull construction. Incident facet indices are grouped for each generator; a right-handed tangent frame is built at that generator and `atan2` angular sorting orders the vertices. The returned index lists are indices into the shared `vertices` array; `polygons` contains the corresponding coordinates, not index lists.
