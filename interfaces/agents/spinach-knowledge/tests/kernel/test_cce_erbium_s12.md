# tests/kernel/test_cce_erbium_s12.m

The registered `kernel/cce_erbium_s12` test checks the analytical [secular CCE-2 pair product](../../kernel/cce/cce_secular_pairs.md) used in the Er:CaWO₄ Fig. S12 example. Dense four-dimensional Hahn propagation independently reconstructs the echo for a three-site tungsten bath with resolvable decay. Singleton and zero-detuning controls require exact unity. It exercises the same numerical function as the figure without sampling the paper-scale ensembles or opening figures.
