# interfaces/nmrpipe/fid2ascii.m

- Signature: `fid2ascii(file_name,fid)`

## Purpose

Writes out 1D, 2D and 3D free induction decays generated by Spinach as ASCII files in the following format [time1, time2, time3, value]. Time is represented by point numbers, the sweep width should be provided by the user to whatever external program is processing the data. Syntax: fid2ascii(filename,fid)

## Physical / mathematical content

- NMRPipe interfaces. These files write or translate Spinach time-domain and spectral data into formats used by NMRPipe-style processing workflows.

## Numerical / algorithmic content

## Parameters / inputs

- filename -a character string
- fid -a numeric data array (structure arrays
- must be exported field by field)

## Outputs

- this function writes a file
- Note: complex data is exported as a double point count in the first di-
- mension. First the reals are given, then the imags.
