# kernel/utilities/tikhonov.m

**Source:** [https://github.com/IlyaKuprov/Spinach/blob/main/kernel/utilities/tikhonov.m](https://github.com/IlyaKuprov/Spinach/blob/main/kernel/utilities/tikhonov.m)

## Purpose

Computes the Tikhonov-regularised solution to `K*x=y` with a positivity constraint on `x`, using a regularised Newton-Raphson method (implemented via constrained numerical optimisation). The solution minimises `norm(K*x-y,2)^2 + lambda*norm(D*x,2)^2` subject to `x >= 0`.

## Behaviour

- Syntax: `[x,err,reg]=tikhonov(K,D,KtK,DtD,H,y,lambda)`.
- Input consistency is enforced by an internal `grumble` subfunction, which errors if any input is non-numeric, if the row dimensions of `K` and `y` disagree, if any supplied `KtK`, `DtD`, or `H` is non-square, or if `lambda` is not a non-negative real scalar.
- The output size is taken from `size(K,2)`.
- If `D` is empty, it defaults to a finite-difference second derivative matrix generated by `fdmat(outsize,5,2,'wall')`.
- If `KtK`, `DtD`, or `H` are empty, they are computed internally as `K'*K`, `D'*D`, and `2*real(KtK+lambda*DtD)` respectively; precomputing these is faster for repeated calls.
- The composite Tikhonov error signal `norm(K*x-y,2)^2 + lambda*norm(D*x,2)^2` and its gradient `2*real(KtK*x - K'*y + lambda*(DtD*x))` are supplied to `fmincon` via an anonymous function.
- Optimisation uses `fmincon` with the `interior-point` algorithm, iterative display, `MaxIterations` of 100, `MaxFunctionEvaluations` of `inf`, an analytic objective gradient, and a fixed Hessian `H` supplied through `HessianFcn`.
- Bounds are `0` (lower) and `inf` (upper) for every element of `x`, enforcing the positivity constraint; the optimisation starts from `ones(outsize,1)`.
- `err` and `reg` are only computed when the corresponding outputs are requested.
- The header notes that, for best numerical performance, `K` should be scaled to have approximately unit 2-norm and `y` approximately unit 1-norm.
- The header also points to `tikhoind.m` for the indeterminate solver.

## Inputs and outputs

**Inputs**

- `K` — kernel matrix; may be complex and non-square.
- `D` — regularisation matrix; leave empty to use the finite-difference second derivative matrix.
- `KtK` — `K'*K`; may be precomputed for repeated calls, otherwise leave empty.
- `DtD` — `D'*D`; may be precomputed for repeated calls, otherwise leave empty.
- `H` — Tikhonov Hessian `2*real(KtK+lambda*DtD)`; may be precomputed for repeated calls, otherwise leave empty.
- `y` — column vector; may be complex.
- `lambda` — Tikhonov regularisation parameter; must be a non-negative real scalar.

**Outputs**

- `x` — real vector; a minimum (subject to positivity) of `norm(K*x-y,2)^2 + lambda*norm(D*x,2)^2`.
- `err` — error signal `norm(K*x-y,2)^2`.
- `reg` — regularisation signal `norm(D*x,2)^2`.
