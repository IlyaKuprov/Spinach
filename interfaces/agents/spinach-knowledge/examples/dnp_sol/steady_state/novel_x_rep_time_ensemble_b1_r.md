# examples/dnp_sol/steady_state/novel_x_rep_time_ensemble_b1_r.m

## Purpose and call

Call `novel_x_rep_time_ensemble_b1_r()` with no arguments from MATLAB with Spinach and the example helpers on the path. It scans repetition time for steady-state NOVEL DNP and compares operation without and with electron flipback. The function declares no return value; it creates and saves a figure. The source estimates hours of calculation.

Source: [MATLAB example](https://github.com/IlyaKuprov/Spinach/blob/main/examples/dnp_sol/steady_state/novel_x_rep_time_ensemble_b1_r.m).

## Spin model and setup

The system is one electron (`E`) and one proton (`1H`) at an X-band magnet setting `sys.magnet=0.34`. The trityl electron Zeeman principal values are `[2.00319 2.00319 2.00258]`; the proton values are `[0 0 5]` (the source calls this a ppm guess). Orientations are set by `(pi/180)*{[0 10 0],[0 0 10]}`. The spin-temperature parameter is `80`; its unit is not stated. The electron is at the origin and the proton lies on the z axis at each sampled distance.

The basis is `sphten-liouv` with `approximation='none'`; `sys.tols.prop_chop=1e-12`, and hygiene is disabled via `sys.disable={'hygiene'}`. Relaxation uses `t1_t2`, diagonal retention, and DiBari equilibrium. `r1n_dnp` supplies a distance- and orientation-dependent function for the nuclear R1 entry, via `r1n_dnp(sys.magnet,inter.temperature,2.00230,1e-3,26,r(n),bet)`; the other configured relaxation entries are `1e3` and `[200e3 50e3]`. These are source values; units are not added where the file gives none. See [r1n_dnp.m](https://github.com/IlyaKuprov/Spinach/blob/main/etc/textbook/r1n_dnp.m).

## Sweeps and calculation

Four Gauss–Legendre distance nodes span 3.5–20 Å, and six Gauss–Legendre B1 nodes span 14–16 MHz (the B1 comment specifies Hz). The 30 repetition-time values are generated by `logspace(-4,-2,30)`; the graph multiplies them by `1e3` and labels the axis in ms. For each distance, the source sets the electron–proton coordinates and builds the Spinach system. For each B1 node it sets `irr_powers` to that node and the 90-degree pulse duration to `1/(4*irr_powers)`. The NOVEL contact duration is `500e-9` seconds; other settings include `flippulse=1`, `addshift=-3.3e6`, and `el_offs=0e6`. The powder grid is `rep_2ang_800pts_sph`. Proton detection is configured as `coil_state(spin_system,'Lz','1H','exact')`, and the experiment spins are `{'E','1H'}`.

At each distance, B1 value, and repetition time, `powder` calls `noveldnp_steady` in the `esr` context. No-flipback shot spacing subtracts one pulse plus the contact duration; flipback spacing subtracts two pulses plus the contact duration. The source normalises the B1 quadrature-weighted signal, then the distance quadrature-weighted signal with `r^2` as the distance Jacobian. The propagation helper is [noveldnp_steady.m](https://github.com/IlyaKuprov/Spinach/blob/main/experiments/hyperpol/noveldnp_steady.m).

## Dependencies

The source uses Spinach system construction and propagation functions `create`, `basis`, `state`, and `powder`, the `gaussleg` quadrature helper, and MATLAB `parfor`; plotting uses `kfigure`, `kylabel`, and `klegend` before MATLAB `savefig`. The NOVEL propagator and R1 helper are linked above.

## Output and scope

The saved figure `novel_x_rep_time_ensemble_b1_r.fig` plots the real proton longitudinal expectation value against repetition time, with separate curves for no flipback and flipback. It depicts this specified pair, relaxation model, and finite distance/B1 quadratures; it is not a result independent of those choices. The code uses `parfor` over repetition times and does not configure a worker count.
