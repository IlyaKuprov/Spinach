# Example knowledge index

## Flux relaxation

- [flux_symmetric](examples/kinetics/flux_symmetric.md): symmetric two-spin transfer.
- [flux_asymmetric](examples/kinetics/flux_asymmetric.md): asymmetric two-spin transfer.
- [frydman_pump_a](examples/kinetics/frydman_pump_a.md) and [frydman_pump_b](examples/kinetics/frydman_pump_b.md): pumping with T1/T2 and flux relaxation.
- [relayed_hyperpol](examples/kinetics/relayed_hyperpol.md): relayed hyperpolarisation with combined relaxation mechanisms.

These examples select `flux` explicitly in `inter.relaxation` and use `inter.flux_rate` and `inter.flux_type`.
