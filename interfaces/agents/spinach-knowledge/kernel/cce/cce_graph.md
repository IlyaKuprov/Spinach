# kernel/cce/cce_graph.m

## Native role and invocation

Internal physical bath connectivity and deterministic cluster-selection scoring service. clexpn supplies resolved engine selection options.

Public simulations enter through `clexpn(spin_system,pulse_sequence,parameters,assumptions)` with a registered experiment.

Internal/expert signature: `graph=cce_graph(model,parameters)`. Engine records are not public experiment parameter structures.

[MATLAB source](../../../../../kernel/cce/cce_graph.m)

## Purpose

Construct physical bath connectivity and deterministic cluster-selection scores.

## Behaviour

- Builds complete, distance, coupling-threshold, or explicit adjacency graphs in stable bath-ID order.
- Uses the spectral norm of the spin-operator pair interaction for coupling connectivity; generalised observed-mediated connections are included when required by the method.
- Checks explicit adjacency symmetry and a zero diagonal, and keeps disconnected vertices available to singleton clusters.

## Inputs and outputs

**Inputs**

- `model` — physical IDs, observed/bath IDs, multiplicities, coordinates in Angstrom, and pair records (`ids`, real Cartesian `tensor` in rad/s).
- `parameters.graph` — `mode`; mode-specific `radius` (Angstrom), `threshold` (rad/s), or `adjacency`; `score` is `coupling_norm` (default), `resonance` (mismatch matrix and positive mismatch_scale, both rad/s), or `supplied` (scores matrix).

**Outputs**

- `graph` — bath_ids, sparse logical adjacency, scores, pair_norm, observed_mediated, approximate, omitted_bath_ids, selection_mode, and requires_convergence.

Second-order projected CCE also retains bath edges mediated by the joint observed-spin system unless `graph.approximate=true`; these edges carry the cross terms generated by the virtual-level susceptibility, even when the bare bath pair tensor vanishes.

For unconnected noise, the cluster graph joins observable-support sites even without a bare Hamiltonian edge, retaining disconnected moment products. Sampled connected noise retains the same support edges to preserve cross-site covariance of the actual finite sampled mixture; deterministic product-state connected noise keeps the ordinary coupling graph. Both ordered and symmetrised reductions use this common graph.

Native noise descriptors carry physical bath-spin support without building a full-bath matrix. Graph selection uses these supports for unconnected or sampled noise, preserving cross terms. The native context computes optional parameters.spectrum only after ensemble reduction and returns diagnostics.spectrum; the Fourier convention remains explicit.

## Internal physical selection option

This table describes the retained graph engine input, not an additional public context signature.

| Field at the engine parameter root | Meaning |
|---|---|
| `bath_radius` | Maximum distance in Angstrom from an observed spin for retaining a bath site; default Inf. This is separate from the graph edge radius. |
