# examples/relaxation_theory/sle_nmr_dd_csa.m

- Signature: `sle_nmr_dd_csa()`

## Purpose

Compares SLE and Redfield calculations for a `15N–1H` protein-amide spin system with dipole–dipole and chemical-shift-anisotropy (DD–CSA) cross-correlation. Calculation time: seconds.

## Physical / mathematical content

At `14.1 T`, the model uses a `15N` Zeeman tensor `[14.89 34.35 0; 34.35 145.74 0; 0 0 150.51]`, a `1H` Zeeman tensor `[30.75 1.31 0; 1.31 22.65 0; 0 0 11.80]`, scalar coupling `10`, and coordinates `[-0.451455 -0.678015 0]` and `[-1.475290 -0.641823 0]`. The proximity cutoff is `4.0`. Both methods use correlation time `5e-9 s`; the SLE maximum rank is `10`, while Redfield relaxation retains secular terms and uses zero equilibrium.

## Numerical / algorithmic content

The complete `sphten-liouv` basis is used without approximation. Both spectra use `15N` `L+` initial and detection states, a sweep from `-0.633e4` to `-0.629e4 Hz`, and `2048` points. The SLE spectrum is generated by `gridfree` with `slowpass`; the Redfield spectrum by `liquid` with the same acquisition settings. The spectra are plotted side by side.
