# examples/kinetics/mas_exchange_1.m

- Signature: `mas_exchange_1()`

## Purpose

This example simulates two-site position exchange for a deuterium nucleus under magic-angle spinning (MAS). The source says that the sites differ in both chemical shift and quadrupolar-tensor orientation and estimates a calculation time of seconds. No DOI or experimental comparison is supplied in this source.

## Spin and exchange model

The spin system contains two 2H entries, with quadrupolar matrices assigned separately to sites 1 and 2. They are generated by `weblab2nqi(0.16e6,0.1,1,0,acos(1/3),2*pi/3)`; these are the literal helper inputs, and the source does not label their units. The scalar-shift entries are `[0.0 3.0]` (again, no unit annotation). A two-site chemical subsystem uses two directed first-order reaction records, each at 2e4 s⁻¹, matching the deuterium between sites, with concentrations `[1.0 1.0]`. Preparation uses concentration-weighted `state`; detection uses unweighted `coil_state`.

The basis is `sphten-liouv` with no approximation. The no-argument function sets a 0.4e6 sweep, 1024 points and 1024 zero-fill points, `axis_units='Hz'`, and `invert_axis=1`. It uses the `rep_2ang_200pts_sph` orientation grid, MAS rate 25000, axis `[1 1 1]`, and `max_rank=12`. The code provides numeric values but does not add units to the MAS-rate or tensor-helper assignments.

## Acquisition and observable

`singlerot(spin_system,@acquire,parameters,'nmr')` generates the signal using the single-rotation MAS acquisition pathway. The code applies exponential apodisation with parameter 6, Fourier-transforms and shifts the spectrum, then plots its real part with `plot_1d`.

The page describes the simulated spectrum only; it does not claim a measured line shape, fitted exchange rate, or quantitative match to data. See the [MATLAB source](https://github.com/IlyaKuprov/Spinach/blob/main/examples/kinetics/mas_exchange_1.m) for the complete interaction and sequence setup.
